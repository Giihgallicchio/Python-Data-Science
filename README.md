#  PROJETO — PYTHON PARA DATA SCIENCE

##  Tema do Projeto
### Atividades Práticas e Laboratórios de Manipulação, Tratamento e Análise de Dados — SENAI

---

##  Sobre o Projeto

Este repositório reúne um conjunto abrangente de laboratórios práticos e desafios voltados para os fundamentos de **Ciência de Dados**, utilizando a linguagem **Python** e a biblioteca **Pandas** como núcleo tecnológico. Os exercícios foram desenvolvidos durante o meu percurso de aprendizagem no **SENAI**.

O projeto cobre toda a esteira inicial de um analista de dados: desde a consolidação da lógica sintática básica de programação até pipelines de carregamento, higienização de strings, engenharia de atributos (Data Preparation), plotagem de gráficos estatísticos e modelagens preditivas iniciais.

---

##  Objetivos do Aprendizado

*  **Data Wranging:** Dominar técnicas de tratamento de anomalias, limpeza de registros inconsistentes e remoção de duplicidade.
*  **Análise Exploratória (EDA):** Extrair valor de conjuntos de dados brutos por meio de agrupamentos, filtros e estatísticas descritivas.
*  **Visualização:** Traduzir métricas numéricas tabulares em representações gráficas claras e interpretáveis.
*  **Raciocínio Analítico:** Desenvolver mentalidade orientada a dados para entender o comportamento de bases complexas e propor análises preditivas.

---

##  Conteúdos e Conceitos Estudados

* **Manipulação com Pandas:** Leitura/carregamento de dados estruturados, transformação de colunas e tratamento de duplicados.
* **Estruturas de Dados:** Implementação avançada de **Sets** (conjuntos com valores únicos) e **Tuplas** (coleções imutáveis).
* **Lógica & Sintaxe:** Aplicação de blocos condicionais (`if`), operadores aritméticos e formatação avançada de textos com `f-strings`.
* **Visualização & Modelagem:** Criação de gráficos analíticos e introdução a fluxos lógicos de análise preditiva.
